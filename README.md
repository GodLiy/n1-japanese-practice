# 聴話

面向已经通过 JLPT N1 的学习者。界面是简体中文，内容是 N1 及以后的新闻、评论、会议、学术短讲、访谈、投诉和交涉，以及阅读和单词本。

不需要账号，不需要服务器。进度、分数、设置和生词只写在这台浏览器的 `localStorage` 里，键名是 `chowa-v1`。打开链接就能用。

稿子都是为这套练习写的，不是 JLPT 真题，也不是哪家媒体、教材或付费课程的原文。

## 安卓应用

可以从 [Releases](https://github.com/GodLiy/n1-japanese-practice/releases) 下载 `chowa-1.0.3.apk`，安装到自己的安卓手机。这一版可以覆盖已经装上的 1.0.0、1.0.1 和 1.0.2。系统若提示未知来源，允许这次安装即可。第一次点「说话」时，手机会询问麦克风权限，点允许。录音只留在这台手机上，不会上传。听、阅读和说使用安装包里的日语录音。安装包用仓库里的旁加载证书签名（`android/sideload.keystore`，口令在 `android/keystore.properties`），以后可以覆盖安装。这不是应用商店的上传密钥。

浏览器里的网站仍然可以用：<https://godliy.github.io/n1-japanese-practice/>

## 能做什么

- **听解**：朗读独白和对话，问要旨、细节、态度和言外之意。答完再看原文、词和中文解释。可以慢速重听。
- **跟读**：按小段跟口语。缩约、填充词、敬语的节拍会单独标出来，并给出书面说法作对照。
- **应对**：会议、投诉、交涉、正式和随意的拒绝。说完后按要点重合打分，并给出参考答案、变体和语体说明。
- **朗读**：句一级的语调、对比重音、长定语和引用。分数只核对字面，音高要自己对照播放来听。
- **阅读**：改写的评论和说明，读完回答大意、细节、作者意图、推断和词在文中的意思。
- **单词本**：点开文章、原文或稿子里的词，看读音、词性、中文释义和例句，也可以按汉字、假名或中文搜索。释义和例句是为这套练习写的。

列表上的标题只说明场景和话题，方便挑选。要听、要阅读、要说的那一点，打开一篇之后才出现。没有单独的语法课。

## 麦克风和浏览器

- 朗读和麦克风可以在 Safari、Chrome、Edge、Firefox、三星浏览器、vivo 浏览器、手机百度、QQ，以及 iPhone、iPad（含 iOS 上的 Chrome）和安卓上使用。语言是日语 `ja-JP`。
- 有日语语音时，朗读使用浏览器或系统语音。对话会尽量用不同的声音；只有一种日语语音时，用音高和语速区分说话人。vivo 浏览器和很多安卓网页（包括微信、QQ）没有可用的日语语音，听练习、跟读、对话、朗读和文章会改播网站自带的日语录音。录音是事先做好、随网页一起提供的，播放时不会把稿子发到网上。默认速度是 1.2 倍（设置里的「较快」），还可以选慢速、正常和快速。iPhone 和 iPad 侧面的静音开关会关掉朗读，也会关掉网页里的录音，要出声请拨到响铃。
- 微信里打开（安卓或 iPhone / iPad）：听在安卓微信里用网站自带录音。麦克风经常被微信拦住。iPhone / iPad 请打开「系统设置 → 微信 → 麦克风」，并点右上角「···」→「在Safari中打开」。安卓点「···」→「在浏览器中打开」。这个网站没有微信公众号接口，不能在微信里强行打开麦克风。句子仍可以打出来评分。
- QQ 或 QQ 浏览器里：听、阅读和说的日语都用网站自带录音，点一下才出声。QQ 里列出的日语语音经常读不出长段，所以不靠它朗读。若点了播放仍然没有声音，点右上角菜单，用 Safari、Chrome 或手机自带浏览器打开。这个网站没有 QQ 接口，不能在 QQ 里强行打开声音。
- 手机百度、百度 App 或百度浏览器里说话：不使用百度自带的识别，而是在你点击后直接录音，再用本机模型转成文字。录音不上传。若点了允许但音量条不动，请到系统「设置 → 应用 → 百度（手机百度或百度浏览器）→ 权限 → 麦克风」打开；iPhone 是「系统设置 → 百度 → 麦克风」。仍录不到时，点右上角菜单，用 Safari、Chrome 或 vivo 浏览器打开。
- 麦克风权限在页面右上角的「设置」里。可以看到尚未询问、已允许或已阻止，也可以当场请求权限。若浏览器已经阻止，需要按设置页里的说明到 Safari、Chrome、Edge、Firefox、安卓或微信的权限里改回来。
- 浏览器自带的语音识别在 Chrome、Edge、Safari 上可用，Firefox 通常没有。识别不到文字、但麦克风确实听到了声音时，会用下载到本机的 Whisper base 模型再听一遍。第一次大约 100MB（模型约 80MB，另有约 22MB 的运行库），只下载一次。录音不上传。模型下不来时，仍可以把句子打出来评分。
- 正式站点是 HTTPS，麦克风需要安全连接。
- 这个网站没有后端，不保存录音，也不把音频传到自己的服务器。浏览器自带的识别可能由浏览器厂商的服务完成，这是那个接口本身的行为。本机模型不会把声音送出去。
- 识别结果会显示出来，可以改掉明显的误转换再评分。说话时能看到音量条，用来确认麦克风确实听到了。识别不能给句调打分。
- 网站自带的对话录音用女声和男声区分说话人，画面上仍会标出谁在说。这些录音用离线日语语音事先生成，说明见 `public/audio/NOTICE.txt`。

## 再加一篇

内容在 `src/content/`：

- `listening.ts` 听解
- `articles.ts` 阅读
- `dictionary.ts` 单词本
- `shadowing.ts` 跟读
- `roleplay.ts` 应对
- `readaloud.ts` 朗读

日语里需要注音的词写成 `[[汉字|よみ]]`。页面上的假名开关只显示这些读音。
